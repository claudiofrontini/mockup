Fondamenta: identità, gestione e sicurezza

Necessario prima del cloud

Intune è il livello di governo del dispositivo/app. Entra ID è il sistema di identità; MSAL permette il login aziendale senza memorizzare password. L'iscrizione MDM, da sola, non implica che la custom app applichi tutte le App Protection Policies.

1Registrare l'app

Il team IT registra un client pubblico iOS in Entra ID, con redirect URI e bundle identifier stabile com.voicerecorder1.app; configurazione per il tenant aziendale.

2Integrare MSAL e Intune

SSO aziendale, Conditional Access quando applicabile, Intune App SDK per la protezione applicativa. Niente credenziali hardcoded.

3Distribuire le policy

Intune distribuisce app e configurazione gestita: tenant, destinazioni consentite, controlli per dati sensibili, condivisione e retention.

Da implementare in Swift: EnterpriseAuthService, ManagedPolicyProvider, DestinationAllowlist. Bloccare l'esportazione se l'identità o la policy richiesta non è valida.

OneDrive for Business · salvataggio manuale

Primo connettore reale

La cartella principale e le sottocartelle si creano solo dopo il primo Salva su OneDrive confermato dall'utente. I contenuti e lo ZIP sono selezionabili; la schermata dell'iPhone non espone l'albero tecnico delle cartelle.

1Permessi Graph

MSAL richiede il consenso necessario, preferendo Files.ReadWrite delegato dove adeguato. Usare il drive aziendale dell'utente autorizzato.

2Cartelle e naming

Verificare/creare VoiceRecorder_Aziendale e il percorso anno/mese/ID. ID immutabile, revisione R01/R02, nomi sanitizzati.

3Upload e conferma

Graph upload session per file grandi, retry e verifica IDs remoti. Solo dopo risposta valida mostrare «Salvato su OneDrive».

SDK/API: Microsoft Graph v1.0, creazione driveItem, createUploadSession; OneDriveConnector con ricevuta, idempotenza e versionamento. Nessun upload in fase di sola trascrizione.

Microsoft 365 Copilot · contenuti e agenti

Dipende dalle licenze

Copilot non è semplicemente un endpoint universale in cui caricare un audio. Si definisce un'esperienza aziendale concreta: documento OneDrive accessibile con permessi M365, oppure flusso strutturato attraverso un agente approvato.

1Definire l'esperienza

Richiesta rapida «Riassumi», «Decisioni», «Attività» o apertura del documento già salvato in Microsoft 365 secondo autorizzazioni.

2Governance M365

Verificare licenza Microsoft 365 Copilot, disponibilità in tenant, accesso ai documenti e permessi SharePoint/OneDrive.

3Agente opzionale

Per un workflow applicativo, progettare un agente/azione Copilot Studio e i relativi connettori, dopo approvazione IT.

Integrazione prevista: documenti Microsoft 365 oppure CopilotAgentConnector. Non considerare la simulazione una conferma di disponibilità API o licenza.

ChatGPT aziendale · analisi su scelta esplicita

Gateway consigliato

Distinguere chiaramente una chat di ChatGPT Business/Enterprise da un'integrazione sviluppata con le API OpenAI: non sono la stessa cosa. Per inviare da VoiceRecorder in modo controllato serve un percorso autorizzato dall'azienda.

1Approvazione IT

Definire workspace aziendale, classificazione dei documenti consentiti, retention e requisiti privacy.

2Gateway server

Implementare un backend aziendale autenticato che usa l'API OpenAI approvata. Non inserire API key sul dispositivo.

3Conferma e risultato

L'utente sceglie i file; il gateway inoltra solo quelli autorizzati. Restituisce riepiloghi e attività, senza upload ad altri destinatari.

Integrazione prevista: EnterpriseAIGateway → OpenAI API, con controllo accessi, logging senza contenuti sensibili e gestione delle chiavi sul server. L'apertura di una chat ChatGPT non equivale a un upload via API.

Gemini aziendale · Google Cloud

Richiede governance Google

Anche qui occorre distinguere Gemini come interfaccia aziendale dalle API per sviluppatori. Per contenuti riservati, progettare una destinazione aziendale governata; non incorporare chiavi API nell'app iOS.

1Scelta del prodotto

Con l'IT stabilire se usare Gemini Enterprise, Vertex AI o una API Gemini approvata, verificando localizzazione e conservazione dati.

2Identità e credenziali

Configurare progetto Google Cloud e identità del backend con privilegi minimi; niente service account JSON nell'app.

3Flusso manuale

Ricevere selezione di file e richiesta esplicita, elaborare tramite gateway, mostrare il risultato solo dopo risposta confermata.

Integrazione prevista: EnterpriseAIGateway → servizio Google Cloud approvato. Verificare sempre i termini aziendali: Gemini API, Vertex AI e Gemini Enterprise differiscono.

Teams, SharePoint, CRM, ERP e API interne

Connettori modulari

Ogni integrazione deve esplicitare scopo, destinazione, permessi, formato supportato e conferma del trasferimento. «Tutti gli strumenti aziendali» non significa aprire una condivisione generica senza controlli.

1Catalogo autorizzato

L'IT configura una allowlist di sistemi con policy per tipo di documento e gruppo utenti.

2Adapter dedicato

Ogni servizio implementa protocollo comune, token sicuri, validazione file, errori comprensibili e ricevuta remota.

3Audit e revoca

Monitorare chi invia, cosa è stato inviato e quando, evitando di registrare il contenuto in log. Supportare la revoca del connettore.

Interfaccia futura: EnterpriseExportConnector → prepare(), transfer(), receipt(), retry(). Una singola schermata «Salva o esporta» per tutte le destinazioni.
Connettori Copilot per altri dati ↗

Requisiti di sicurezza e UX

  • Nessuna sincronizzazione automatica: anche l'archivio OneDrive si attiva solo dal dettaglio della registrazione.
  • Selezione obbligatoria: audio, trascrizione, traduzione, speaker, manifest e ZIP singolarmente; solo contenuti scelti dall'utente.
  • Nome e revisioni stabili: identificativo univoco, data UTC, versione R01/R02, checksum e ricevuta remota quando disponibile.
  • Token e segreti: token mobili protetti in Keychain; chiavi dei provider AI solo nel backend; nessuna telemetria di audio o testo.
  • Fail closed: connettore non configurato, policy negata o upload fallito = nessun falso «salvato» e nessuna cancellazione locale.

Piano di integrazione progressivo

  1. Fase A · Demo attuale: UI, ricerca, selezione file, ZIP e servizi simulati nel browser.
  2. Fase B · App Swift: queue locale, export reale su richiesta, test Xcode e protezione archivi.
  3. Fase C · Microsoft: MSAL/Entra, Intune App SDK, Microsoft Graph e permessi per OneDrive.
  4. Fase D · AI e altri tool: accordo IT, gateway enterprise, connettori Copilot/ChatGPT/Gemini e audit.
